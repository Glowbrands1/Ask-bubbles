Subject: [PATCH 3/4] Fix QA payroll amount: the comma that ends a clause is
 not part of the amount

Root cause (src/lib/forms/payroll-deduct.ts, MONEY): the amount pattern
`\$\s?\d[\d,]*` allowed any run of digits and commas, so "payroll deduct $25,
she was late" read the amount as "$25," and the Action Plan said "$25, will be
deducted from Pat's pay." The amount was right; the text on the HR record was
not. Present on both apps' main and branch.

A comma is now part of an amount only between digit groups ("$1,250"). "she owes
$25, payroll deduction applies" no longer takes "$25," as the amount; the plan
says "A payroll deduction applies." No Yes/No reading changes.

Tests: 7 cases added to qa-f01b-payroll-fail-safe.test.ts; 3 fail before.
All payroll test files pass.
