## Interim — replace when the originals arrive

- **Logos:** these are 720px PNGs extracted from the guideline PDF. Replace them
  with the vector files (SVG/EPS) from Buff City Soap's "National Logos" folder,
  keeping the file names.
- **Photos:** replace with full-resolution, text-free originals from the
  approved photography folder.
- **Background artwork:** the pattern tiles and the line-up were extracted from
  screen-resolution copies of the official illustrations. Replace them with the
  vector or full-resolution originals from Marketing, keeping the file names and
  the same White / green colouring; the CSS and opacities do not change.

Logo rules (2023 guidelines, pp.21–26): use the stacked logo wherever it fits;
only Tokyo Green, White, Charcoal or Immaculate Cloud; no box, outline, drop
shadow, stretching or recolouring; clear space equal to the height of the "B".
